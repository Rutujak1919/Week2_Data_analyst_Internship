# Week 2 – Data Analyst Internship

## Python for Data Analysis and SQL for Data Analysis

### Project Description
This repository contains my Week 2 internship assignments, covering Python for Data Analysis and SQL for Data Analysis using a sales dataset of 200 records.

### Dataset
**File:** SQL_Sales_Dataset_200_Rows.xlsx - Sheet1.csv

The dataset contains 200 rows and 10 columns, including:
- order_id
- customer_name
- order_date
- category
- sub_category
- product_name
- quantity
- unit_price
- total_price
- region

### Part 1: Python for Data Analysis

The following tasks are completed using Python and Pandas:

1. Load a CSV file using Pandas and display basic information.
2. Handle missing values and duplicates using Pandas.
3. Group data by category and find total revenue.
4. Sort data by multiple columns using Python.
5. Create a correlation matrix for numerical columns.

### Part 2: SQL for Data Analysis

SQL topics covered:

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- SUM, AVG, COUNT
- Joins
- Subqueries
- CASE statements
- Find top customers
- Calculate average order values
